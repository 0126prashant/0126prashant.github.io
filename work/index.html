RETRIEVAL / RERANKING / GENERATIONSystem overview
The approach

Built MongoDB Atlas Vector Search retrieval, multi-corpus reranking, and SSE token streaming. Rerouted hot-path case lookups through a compound search index to remove expensive collection scans.

Engineering decisions
  • Separate semantic retrieval from exact case-lookup fast paths.
  • Rerank across corpora before constructing the answer context.
  • Stream the answer through SSE so users can read as it arrives.
The outcome<400mscase-lookup latency

Reduced case-lookup latency from 7–26 seconds to under 400 milliseconds, while supporting grounded answers across 15,000+ documents.

USAGE / PRICING / RECONCILIATIONSystem overview
The approach

Engineered an event-sourced billing pipeline with per-token metering, cost-plus pricing, tiered rate cards, and pay-as-you-go multipliers. Distributed cron locks and idempotent deduplication protect processing.

Engineering decisions
  • Preserve usage events so charges can be traced to their source.
  • Use idempotent processing to avoid duplicate charges.
  • Keep provider cost, plan pricing, and billable usage separate.
The outcome6LLM providers metered

The billing engine powers all platform AI revenue, with metering across six LLM providers.

DEMAND / SCALE / RESILIENCESystem overview
The approach

Migrated backend services to Azure Kubernetes Service with Helm and KEDA scale-to-zero autoscaling. Audited 70 deployments. Built direct-to-Blob SAS uploads, ranged PDF previews, and asynchronous Ghostscript compilation.

Engineering decisions
  • Match resource allocation to workload demand.
  • Upload large files directly to cloud storage.
  • Move document compilation out of the request lifecycle.
The outcome~33%lower projected cloud spend

Reduced projected cloud spend by approximately 33% and eliminated server out-of-memory failures caused by large document bundles.
